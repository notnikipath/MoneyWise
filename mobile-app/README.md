# Mobile App Blueprint (React Native)

This folder documents how the React Native client can connect to MoneyWise APIs.

Recommended stack:

- Expo + React Native
- TanStack Query for API state
- SecureStore for token storage

Primary screens:

1. Transaction quick add (manual + voice-ready placeholder)
2. Budget limits and alerts
3. Goal progress and monthly required contribution
4. Portfolio value and risk badge
5. Widget-style summary cards

Gateway base URL for emulator:

- Android emulator: `http://10.0.2.2:8580`
- iOS simulator: `http://localhost:8580`
